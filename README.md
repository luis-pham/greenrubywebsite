## Minimum Requirements
- PHP 8.0

## Install
- git clone: http://gitlab.amitech.vn/green-ruby/cms.git
- cd cms
- composer install

# Build CSS, JS
- yarn install
- For development: yarn run dev
- For production: yarn run prod

# Run project
- php artisan serve
